C-Kite Redesign

Реальна форма, справжня топологія конструкції, умовна фізика.

Класичний C-Kite (Leading Edge Inflatable) — проста, геометрично виразна та впізнавана форма для вигаданого метаморфічного світу.

1. Реальний прототип

Орієнтир: Slingshot Fuel, класичний C-подібний кайт. Для нашого світу беремо чотиристропну конфігурацію з прямим кріпленням до чотирьох кутів крила, без складної розгалуженої системи. Передня надувна кромка та поперечні ребра формують впізнаваний силует.

Це автономна HTML-версія попередньої специфікації: зовнішні фотографії реальних кайтів не включені; геометрію показано оригінальними векторними схемами та інтерактивною моделлю нижче.

Той самий параметричний ескіз: JavaScript + Canvas 2D, без бібліотек і мережевих запитів. Відсотки на другому слайдері — умовна шкала параметра D, а не фізична відносна товщина.

Як побудовано модель

Це не імпортована 3D-модель і не симуляція тканини. Кожна точка поверхні обчислюється функцією P(u,v), де u ∈ [-1,1] — координата вздовж розмаху, а v ∈ [0,1] — координата від передньої до задньої кромки.

function p(u, v) {
  const a = u * A * Math.PI / 360;
  const r = 1.75;
  const chord = 1.03 - 0.15 * u * u;
  return [
    r * Math.sin(a),
    r * (Math.cos(a) - 0.55) + D * Math.sin(v * Math.PI),
    (v - 0.42) * chord + 0.16 * u * u
  ];
}

A задає повний кут C-подібної арки в градусах; r — радіус; D — додатковий вигин тканини. Хорда звужується на кінцях за квадратичним законом, а доданок 0.16*u*u зміщує кінці крила вздовж хорди. Синус від v дає опуклість усередині полотна й нульовий додатковий вигин на обох кромках.

Для ескізу поверхня розбивається на 40 × 14 чотирикутників. Їхні 3D-координати повертаються навколо двох осей, ортографічно проєктуються на Canvas, сортуються за глибиною та зафарбовуються. Каркас, шви і стропи використовують ту ж функцію p(u,v), тому залишаються прив'язаними до поверхні при зміні її параметрів. У Three.js замість ручної проєкції достатньо створити вершини та індекси трикутників у BufferGeometry і обчислити нормалі. Ніякого фізичного solver не потрібно.

4. Специфікація для агента

C-Kite Redesign

Objective

Replace the existing flat diamond kite with a recognizable classic four-line C-shaped LEI traction kite.

Reference: Slingshot Fuel traditional C-Kite.

Geometry

  • Single-layer curved fabric surface.
  • C-shaped spanwise arc, approximately 145 degrees.
  • Aspect ratio approximately 3:1, measured using the developed span.
  • Slight chordwise curvature.
  • Thick tubular leading edge.
  • Thin trailing edge.
  • Three chordwise supporting struts.
  • Four direct line attachment points at the wingtip corners.
  • Two front power lines.
  • Two rear steering lines.
  • Simple control bar with central raft attachment.
  • Terracotta fabric, dark brown structural elements.
  • No branding or decorative graphics.

Implementation

  • Procedural Three.js BufferGeometry, approximately 48 × 16 subdivisions.
  • TubeGeometry for structural elements.
  • Double-sided fabric material.
  • Subtle fabric seams.
  • Smooth normals.
  • Reuse geometry and materials during animation.
  • Update rope endpoints from the actual kite transformation.

Animation

  • Slow lateral oscillation.
  • Gentle pitching and banking.
  • Slight fabric deformation depending on the existing weather state.
  • Smooth orientation changes following raft navigation.

Constraints

  • Preserve existing navigation logic.
  • Preserve existing weather behavior.
  • Preserve existing camera and controls.
  • No additional physics simulation.
  • No aerodynamic calculations.
  • No cloth solver.
  • No new dependencies.

Acceptance criteria

The kite must be immediately recognizable as a real kitesurfing kite when viewed from the raft, from the shore and from the side. Its fabric, supporting structure and four-line attachment topology must remain visually consistent during movement.

Implementation note: the viewer preserves the earlier illustrative constants and subdivision count; these do not enforce the target 3:1 aspect ratio. Treat the target proportions as approximate art direction and calibrate span/chord in the production mesh if needed. This is a visual design, not a real-world kite construction specification.
