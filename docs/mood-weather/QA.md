# QA: mood-weather

Локально з каталогу `D:/work/_tools/water-3d/Ultra-Water`: `npm install`, потім
`npm run dev`. Стенд — `http://localhost:5199/`; якщо вже працює, другий процес
не запускати. Інтернет не потрібен. За правилом `AGENTS.md` стенд лишається
запущеним після рев'ю.

До M4 стан ставиться з консолі браузера (F12): `app.mood.set(v, a, t)` —
`v` хмарно −1 … +1 ясно, `a` тиша −1 … +1 вітер, `t` світанок 0 … 1 захід
(без `t` — поточний). Світ стає таким одразу, без переходу (переходи — M2).
`app.mood.state()` — поточний стан. Слова в стані — ключі локалі (рядки — M3).

## M1a. Дані, прив'язки й один писар сонця, без UI

**Прийнято власником через `handoff:next` 2026-11-23** (з відкритим рішенням
щодо підлоги §6 п.5 — див. «Відомі провали M1a»). Guard зелений 0.30 с
(OWNER-4 0, BOUNDARY-2 8 файлів, TYPES-1 21); `npm test` 92/92 (`tests/mood.test.js`
26); `probe-scene-env-identity` Δ 0 на 5 шотах (80.8 с, еталон знято до змін);
`probe-mood-m1a`: anchors 9/9 (1 с), field Δ 0 м (10 с; мутація «поле за
поточним сонцем» — Δ 937 м), readable 5/27 (257 с).

Що з'явилося: матриця погоди й крива сонця як дані
([src/environment/mood.js](../../src/environment/mood.js): `MOOD_MAP_V1`,
`sampleMood` білінійно, `SUN_PATH_V1`, `sunAt`), прив'язка каналів моря
([src/environment-bindings/seaBinding.js](../../src/environment-bindings/seaBinding.js):
вітер, хвилі, прибій, бризки, колір і прозорість води, туман рельєфу й води;
сюди ж переїхали `WATER_PRESETS`), дебаг-API `app.mood`. Сонце тепер пише лише
`env.set()` модуля оточення: шоти, слайдери Controls і `app.mood`. Шоти й поле
історії стоять на сталому азимуті заходу 205°, а не там, де сонце зараз.
**Без `app.mood.set` на екрані не змінилося нічого** (проба identity: Δ 0 на 5
шотах).

### QA-M1a-1. Світ відкривається як раніше

**qa:mode:** browser
**qa:open:** `http://localhost:5199/?desktop`
**qa:action:** нічого; у консолі виконати `app.mood.state()`.
**qa:inspect:** сцена + вивід консолі.
**qa:expected:** шот Lagoon, сонце високо, як до фази. Консоль:
`{ t: 0.1, v: 1, a: -1, flow: false, custom: true, map: 'mood@1', anchor: 'A9', words: ['calm', 'peace'] }`
— `custom: true`: до першого `set` світ належить Controls. Покриває
`probe-scene-env-identity` (кадр Δ 0 на Golden hour, Lagoon, Aerial, Underwater,
Tiles).

### Відомі провали M1a

- **Підлога §6 п.5 не тримається на чорних тайлах** (`probe-mood-m1a`, 2026-11-23,
  desktop 1280×720, шот Tiles, `story-8-frames-hibrid`). Тайли фікстури —
  кольорові картинки; міряються тайли з альбедо рівно білим (916 з 23 678) і
  рівно чорним (5 962) — маска з трьох рендерів (як є / альбедо 0 / альбедо 1).
  Чорні тайли — тло картинок, яке лежить урівень з водою: у кадрі їхня
  яскравість — це майже яскравість води над ними, тому вона росте з відбиттям
  неба.

  на ±0.03 (стан автоекспозиції перед першим випадком).

### Свідомо не зроблено в M1a

- Віджет, стан «власне» від ручної зміни Controls (M1b). Поки що слайдер
  Controls після `app.mood.set` просто змінює світ, `custom` лишається `false`.
- Плавні переходи (M2): `set` миттєвий, небо перепікається одразу.
- `cloudSpeed` якорів і `sunTint` не діють (анімовані хмари — E2; `tint` —
  нейтральний, доки власник не відкалібрує).
- Слова — ключі (`calm`, `peace`), не рядки локалі (M3).
- URL `?mood=`/`?day=` — M4.
